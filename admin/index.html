स्थिर वेबसाइट

प्रोफाइल माहिती बदलण्यासाठी

GitHub Pages HTML, CSS, JavaScript आणि चित्रे दाखवते; ती फॉर्ममधून बदल कायम ठेवणारा सर्व्हर चालवत नाही.

प्रोफाइल अपडेट करा

  1. data/profile.json मध्ये नाव किंवा पद बदला.
  2. बदल GitHub वर push करा. Actions workflow स्थिर वेबसाइट पुन्हा तयार करेल.
  3. फक्त स्थानिक पूर्वदृश्यासाठी `npm start` चालवा; सर्व्हरयुक्त आवृत्तीत प्रशासक डॅशबोर्ड उपलब्ध आहे.

GitHub Pages मध्ये पासवर्ड किंवा खाजगी माहिती ठेवू नका. या पृष्ठावर प्रशासक लॉगिन फॉर्म मुद्दाम दाखवलेला नाही.
