# जितेंद्र बाळासाहेब बडेकर — सार्वजनिक प्रोफाइल संकेतस्थळ

मराठी-प्रथम सार्वजनिक प्रोफाइल संकेतस्थळ. नाव, इंग्रजी पर्यायी नाव आणि पद हे `data/profile.json` मधून येतात. प्रशासक डॅशबोर्डमधील बदल सर्व्हरवर या फाइलमध्ये जतन होतात आणि पुन्हा सुरू केल्यानंतरही टिकतात.

मुख्यपृष्ठ `/`, प्रोफाइल `/about`, आणि स्वतंत्र सार्वजनिक विभाग `/political-journey`, `/party-work`, `/social-work`, `/department`, `/schemes`, `/activities`, `/news`, `/gallery`, `/reports`, `/contact`, `/privacy-policy` आणि `/accessibility` येथे उपलब्ध आहेत. नोंद/मंजूर सामग्री नसलेल्या विभागांमध्ये पडताळणी सूचना दिसते.

## सुरू करण्यासाठी

1. Node.js 20.6 किंवा त्यानंतरची आवृत्ती स्थापित करा.
2. `.env.example` ची प्रत `.env` नावाने तयार करा आणि `ADMIN_PASSWORD` साठी मजबूत, स्वतंत्र पासवर्ड ठेवा.
3. `npm start` चालवा.
4. `http://localhost:3000` उघडा. प्रोफाइल संपादित करण्यासाठी `http://localhost:3000/admin` उघडा.

या प्रकल्पात तृतीय-पक्ष पॅकेजेस नाहीत. `npm run check` JavaScript फाइल्सचे syntax तपासते.

## प्रशासक प्रवेश आणि माहिती जतन

लॉगिन पासवर्ड फक्त सर्व्हरच्या `.env` फाइलमधून वाचला जातो; तो client code किंवा repository मध्ये ठेवू नका. लॉगिन session HttpOnly, SameSite cookie वापरते. उत्पादनात HTTPS आवश्यक आहे (`NODE_ENV=production` केल्यास cookie वर `Secure` flag लागतो). प्रोफाइल बदल `data/profile.json` मध्ये जतन होतात; त्या फोल्डरचा बॅकअप घ्या. सध्या एकच प्रशासक खाते आहे; वापरकर्ता/संपादक भूमिका किंवा डेटाबेस जोडलेला नाही.

## पडताळणी व पुढील सामग्री

राजकीय प्रवास, पूर्वीची पदे, सामाजिक उपक्रम, विभागीय काम, बातम्या, योजना, आकडे, संपर्क तपशील आणि कार्यक्रम यांसाठी पडताळलेली माहिती उपलब्ध नसल्याने त्या जागा स्पष्टपणे `पडताळलेली माहिती जोडायची आहे` असे दाखवतात. प्रकाशित करण्यापूर्वी संबंधित स्रोत आणि माहितीची शेवटची पडताळणी नोंदवा. संकेतस्थळावर अधिकृत पक्षचिन्ह किंवा राजकीय व्यक्तीचे छायाचित्र दिलेले नाही; प्रशासकाने अधिकृत वापरासाठी मंजूर केलेली सामग्री उपलब्ध झाल्यावरच ती जोडा.

हे वैयक्तिक/पक्षीय प्रोफाइल संकेतस्थळ आहे. ते पुणे जिल्हा परिषद किंवा महाराष्ट्र शासनाचे अधिकृत संकेतस्थळ असल्याचा दावा करत नाही. सरकारी योजना किंवा तक्रारींची माहिती देताना अधिकृत स्रोताशी पडताळणी आवश्यक आहे.
